# GMOインターネットグループ GMO流ランチェスター戦略のポイント

> このドキュメントは、本リポジトリにおける施策・意思決定の判断基準となる「思想」である。
> 何かを実行・提案する際は、必ずこの戦略に沿って検討すること。

ランチェスター戦略とは、「戦闘」における武器と兵力の関係を法則化した「ランチェスター法則」と、「戦争」における軍事資源の有効配分を理論化した「クープマンモデル」をベースに、ビジネス＝競合との戦いに勝つためのマーケティング成功法則として再構築したものである。

F.W.ランチェスター氏は、第一次大戦期のイギリスの航空工学エンジニアである。戦闘機性能と戦果の因果関係を研究し、ランチェスター第一法則、第二法則を導き出した。B.O.クープマン氏は、第二次大戦期のアメリカの数学者である。ランチェスター法則を前提に、戦略と戦術の最適配分を研究し、意思決定の科学の基礎を築いた。これらの研究をベースに、戦後日本で田岡信夫氏が、シェアの理論、販売戦略の科学として体系化したものがランチェスター戦略である。

## 【1】前文

GMO流ランチェスター戦略とは、従来のランチェスター戦略に、我々が開発したインターネット時代の新しい視点・戦い方を加味したものである。

インターネット産業の成熟化に伴い、誰もが一定の成果を上げられるレース型（競馬・競輪型）競争、すなわち1位以外も生きられる時代は終わり、パイの奪いあいとなるゲーム型（格闘技型）競争、つまり1位だけが生き残る時代へと移行するなか、小が大に勝つためにはゲームのルールと勝ち方の定石を知り、実践する必要がある。

## 【2】前提

### 1. ビジネスは戦（いくさ）である
ビジネスはお客様の笑顔の領地=シェアを広げる戦（いくさ）である。戦である以上、勝たなければならない。ビジネスにおいて売り手と買い手が満足するのは当然のこと、社会に貢献できてこそよいビジネスである。近江商人の経営哲学＝三方よしは、現代のビジネスにも生きている。

### 2. ナンバー１主義
すべてのスペック・価格・デザイン・セキュリティ（安心・安全）で競合より勝り、かかわるすべての仲間が自信と誇りを持ち、笑顔になれるナンバー１のサービスこそが、戦いに臨む我々の武器である。右手に「ナンバー１のサービス」、左手に「誇り」を持って、お客様に「感動」を売ろう。

### 3. 戦場の選択（5つの成功法則）
戦場の選択には法則がある。自らの強みを活かしてナンバー１になるだけでなく、勝ち続けられる領域を選ばなければならない。
1. なくならないビジネスかどうか？
2. 伸びているかどうか？
3. ストック型かどうか？
4. 刀の柄（つか）を持っているか？
5. 複利かどうか？

(1)ビジネスは「なくならないビジネス」と、「なくても大丈夫なビジネス」に分けられる。前者は生き残り、後者は淘汰される (2)伸びている＝成長性のあるマーケットにこそチャンスがある。勝つためには「伸びている・伸びていく」マーケットに注力する (3)ビジネスには「スポット（フロー）型」と「ストック型」がある。スポット（フロー）型も、アイデア次第でストック型になる (4)他人にコントロールされるのではなく、自分でコントロールできるビジネスを展開する (5)ビジネスには単利と複利がある。お客様の満足がアップセル、クロスセルにつながり、さらにお客様の感動が、新たなお客様の紹介につながる。この複利のビジネスこそが我々が目指すビジネスである。

## 【3】結論

### 1. ランチェスター戦略のゴール
勝てる領域（戦場）を選び、その領域に重点的に経営資源を投入し、ナンバー１になることである。ナンバー１になったら、勝利のノウハウを活かして次の戦場を攻略する。戦線の無秩序な拡大は、戦力の希薄化を招き、強者との戦力差をより大きなものにしてしまうだけである。なお、一点集中することは他を捨てることであり、トップの決断力と関係者の共通認識が肝要となる。

### 2. ナンバー１とは
「シェア1位で、且つ2位を射程距離圏外に引き離している企業」のことである。2位と3位を足すと逆転可能な1位は「なんちゃって1位」であり、真のナンバー１とは言えない。

### 3. シェア（市場占拠率）
シェアはランチェスター戦略における基本である。「シェア＝自分の占拠している範囲÷市場範囲」であるが、すなわち勝ち目のある「市場範囲」を選び、経営資源を重点投下することが戦略の重要テーマである。限定された市場範囲におけるシェアは一般に明らかではなく、自ら調べなければならない。正確な数字が分からない場合は、概算でも推測でも構わない。ある程度の目安でも、戦略の方向性を決定するには十分役に立つ。

## 【4】理論

### 1. ランチェスター第一法則
刀や鉄砲のような単発兵器を用いた局地戦・接近戦、すなわちコールセンター営業や対面営業など、1対1の戦いの場合、「戦闘力＝武器性能×兵力数」という式が成り立つ。戦闘力＝競争力、武器性能＝商品力・情報力等の「質」、兵力数＝セールスマン数・電話機の台数・売り場面積等の「量」と読み替えるなら、相手より質・量で上回れば勝てることを示す。兵力数が同じなら、勝敗は武器性能＝商品力・情報力等の「質」の差によって決まる。ナンバー１サービスを前提とする我々の戦いでは、兵力数の差をいかに小さくするかが勝敗を決するポイントになる。

### 2. ランチェスター第二法則
機関銃のような確率兵器を用いた広域戦・遠隔戦、すなわちCM配信や広告出稿など、1対多の戦いの場合、「戦闘力＝武器性能×兵力数の2乗」という式が成り立つ。戦闘力＝競争力、兵力数＝代理店数・広告出稿量・資本力・調達力等の「量」の差が、勝敗に対してより大きく寄与する。

### 3. 射程距離「3:1（サンイチ）」の理論
局地戦においては3倍、広域戦においては√3倍＝1.73倍のシェア差をつければ逆転困難である。相手の3倍（√3倍＝1.73倍）の資源を投入すれば必勝であることを示している。

### 4. 七つのシンボル目標値
最終的な勝利を得るまでのマイルストーンであり、どこまで占拠すると勝利の可能性が高まるかを示している。
- **74%** 独占シェア。市場活性化とのバランスで最大値、細分化した市場範囲におけるシェアの最終目標。
- **42%** 相対的安定シェア。3社以上の競争状態を前提に独走するための条件。
- **26%** 差別的優位シェア。1位の最低条件。
- **19%** 並列的上位シェア。上位グループ入りの最低条件。
- **11%** 市場的影響シェア。市場全体で注目されるが、上位者からつぶしに遭う。
- **7%** 競合的存在シェア。存在を認知される最低限のシェア。
- **3%** 市場橋頭堡シェア。当該市場範囲で戦う足がかりとなるシェア。

マーケット全体のシェア状況は (1)→(2)→(3)→(4)→(5) または (1)→(3)→(2)→(4)→(5) で推移する。

1. **分散型**：1位≦26%（1位が流動的）／各社間格差が√3以内（逆転可能性あり）
2. **相対的寡占型（三強型）**：1位＋2位＋3位≧74%／1位≦2位＋3位／1〜3位の格差が√3以内
3. **二大寡占型（二強型）**：1位＋2位≧74%／1位≦2位×√3
4. **絶対的独占型（一強型）**：1位≧42%／1位≧2位×√3
5. **完全独占型（独占型）**：1位≧74%

## 【5】実践

### 1. GMO流強者と弱者
強者とは「シェアが1位の企業」、弱者とは「シェアが1位でない企業全て」である。強者は広域戦・確率戦・遠隔戦・総合主義・誘導作戦、戦場全体において「フルミート＋差別化」で戦う。弱者は局地戦・一騎打ち戦・接近戦・一点集中主義・陽動戦、選んだ「局地」において「フルミート＋差別化」で戦う。

### 2. GMO流フルミート
競合の動向を1時間ごとにチェックし、差別化攻撃を仕掛けられたら即時ミート（同質化）することで競合を無力化する。すぐにミートできない場合は、期限を明確にした提供予告を即時発表する。恐れることなく、即時ミートを繰り返していれば、競合は戦意を喪失し、戦いに勝つことができる。

### 3. GMO流差別化
フルミートに加えて、武器性能（質的部分）を向上することである。(1)すぐにミートされる差別化は差別化とはいえない (2)顧客に評価されない差別化は差別化とはいえない (3)複数の差別化を掛け算で相乗効果 (4)自業界の非常識は他業界の常識 (5)小技・小手先も大切 (6)営業は情報装備し、提案型・ソリューション型へ。

### 4. 競争目標と攻撃目標
自社よりシェア上位の企業は「競争目標」であり、競争目標から攻撃を仕掛けられたら弱者として差別化戦略で戦う。自社よりシェア下位の企業は「攻撃目標」であり、攻撃目標に対しては強者としてミート戦略で戦う。

### 5. 「足下の敵」攻撃の原則
最も効率的にシェアアップを狙うなら、シェア順位直下の企業を攻撃目標としてシェアを奪うのが定石である。奪ったシェアの2倍がシェア差となり、射程距離圏外へ突き放す可能性が高まる。

## 【6】応用

### 1. ナンバー１になるために
(1)目標を持つ（「○年後に□でナンバー１になる」）。○は3年以内、□は市場範囲(戦場)の設定。市場範囲(戦場)は①カウントできること②アクセスできること③ボリュームがあること――に留意しつつ細分化し、「強いものをより強く」というダントツ発想を前提に、顧客の視点・評価軸の中から集中すべき一点を選択し、設定する (2)「自分は何屋で、得意技は何で、あなたに何をしてあげられる」という部分を顧客に20秒以内で説明できるようにする (3)自らの権威付けや、専門分野の情報をまとめて見識を加えて専門家の地位を産み出すなどの手法で、ブランド力の向上に寄与する。

### 2. 強みの開発法
(1)他業界のやり方をモデルに自業界に持ち込む (2)顧客密着ナンバー１になる (3)好きなことを徹底的に掘り下げる――などから強みを見出し、磨き上げてナンバー１を目指す。強みの種が見つかりにくい場合には顧客に聞いてみても良いし、比較的良い「小技」の掛け合わせでも立派に武器になる。ナンバー１になったらその過程を標準化・具体化・プロセス化してノウハウにする。

## 【7】究極の戦略
究極の戦略とは「競争に巻き込まれないこと」「顧客に比較されないこと」「戦わずして勝つこと」「市場シェア74％を握ること」である。これにより価格決定権を握り、自らがルールとなり市場を支配することが出来る。
