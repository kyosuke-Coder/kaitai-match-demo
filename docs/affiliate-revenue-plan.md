# 収益化プラン v6：セルフケア自社サービスモデル（高単価プログラム × 非属人メディア × アプリ）

作成日: 2026-09-02（v6: 代行系を廃し、すべて自社サービスで構成）
目標: **12ヶ月で月の手取り100万円**（月利益135万円）— 固定制約
制約: PC or iPhone 1台 / 月間固定費 上限8,000円 / テーマ: セルフケア（睡眠・自律神経・QOL）

## 0. 結論：自社サービス三層モデル

他人の商品を売る（アフィリエイト）でも他社の作業を請ける（代行）でもなく、**すべて自分が価格決定権を持つ自社サービス**で構成する。

```
Layer 1【主砲】 「12週間 睡眠・自律神経セルフケア改善プログラム」198,000円
                無料個別相談 → 申込。週1オンライン面談 + デイリー習慣サポート
                → 高単価だからこそ広告が黒字で回り、オーガニックの天井を破れる
                → 12ヶ月目中央値 90万円（広告費差引後）

Layer 2【集客・資産】 非属人セルフケアメディア（SNS週3-4→note→有料note/会員/外貨テンプレ）
                → 無料相談への最大の送客源 兼 それ自体で月15万円

Layer 3【スケール】 習慣トラッキングLINEアプリ（自分で開発。KAITAI MATCHのLIFF技術を転用）
                → プログラムの提供ツールとして開発し、10ヶ月目からB2Cサブスク1,480円/月として公開
                → 12ヶ月時点では小さいが、24ヶ月目以降に本人の稼働と収益を切り離す装置
```

### なぜ高単価プログラムが主砲か（数学的根拠）
- 低単価SaaS/アプリを主砲にすると135万には約90社×1.5万円が必要で、12ヶ月では届かない
- 198,000円なら**月7件で135万**。無料相談→成約25%なら月28件の相談で足りる
- 最重要: 広告CPA（無料相談1件 約1万円）に対し1成約の価値が約17万円 → **CAC約4万円 vs 客単価19.8万円**で広告が回る。視聴者数依存から脱出できる唯一の構造

### シミュレーション結果（2万回試行）

| 指標 | v5(受託型) | **v6(自社サービス型)** |
|---|---|---|
| **手取り100万を12ヶ月以内に達成** | 14.6% | **26.8%** |
| 同 18ヶ月以内 | 46.8% | 48.7% |
| 12ヶ月目の月利益 中央値 | 86万円 | **105万円** |
| 12ヶ月目 p75 / p90 | 112万 / 144万 | **136万 / 158万** |
| 12ヶ月目 p10（下振れ） | 52万円 | **23万円** |

**中央値で100万を超える唯一のモデル**。ただし下振れは受託型より重い（成約率と広告経済性に依存するため）。上振れを取りに行き、下振れは6ヶ月目のチェックポイント（後述）で早期検知して対処する。

## 1. Layer 1: 12週間セルフケア改善プログラム（主砲）

### 商品設計
- **対象**: 眠れない・疲れが抜けない・自律神経の乱れを感じる20〜40代（医療対象者は除外し受診を案内）
- **内容**: 初回アセスメント → 週1回30分のオンライン面談×12回 + 習慣トラッキング（Layer 3アプリ）+ チャットサポート
- **価格**: 198,000円（一括。分割はStripeで3回まで）。モニター期は半額
- **立て付け**: 医療・治療ではなく**習慣改善コーチング**。効果保証をしない。特商法表記・中途解約規定を明文化
- 提供は半属人（実名・声。顔出しは任意）。SNSの非属人運用とは分離する

### 販売ファネル
```
メディア/広告 → LP → 無料個別相談(30分) → 提案 → 申込
相談予約率: note読者の1.2% / 広告CPA: 相談1件 約1万円
成約率: 25%目標（30%で確率が1.4倍になる最重要KPI）
提供キャパ: 月9件前後 → 9ヶ月目にグループ形式併設で月12件超へ
```

### 広告運用ルール
- 6ヶ月目から開始。**前月利益の35%を上限**に投下（固定費ではなく変動費）
- 撤退ライン: CAC（相談CPA÷成約率）が客単価の40%を超えたら即停止しオーガニックに戻す
- 12ヶ月目の想定広告費 約36万円/月（利益は差引後で計上済み）

### スケジュール
- 1〜2ヶ月目: プログラム設計・LP・無料相談の型作り
- 2〜3ヶ月目: **モニター3〜5名（半額99,000円）**→ 事例・数値・声を獲得（この時点で初売上30〜50万円）
- 4ヶ月目〜: 正規販売開始（オーガニック）
- 6ヶ月目〜: 広告開始
- 9ヶ月目〜: グループ形式併設でキャパ拡張

## 2. Layer 2: 非属人メディア（集客エンジン・資産）

v4設計を週3〜4投稿で継続。役割が「直接収益」から「**無料相談への送客と信頼形成**」に変わる:
- SNS（図解・テキスト動画）→ note無料記事 → ①無料相談LP ②有料note 1,980円 ③会員1,480円 ④アフィリエイト
- 外貨トラック: 英語圏Self-Care Journalテンプレ（Gumroad/Etsy、Pinterest集客、11〜1月の季節山に初出品を間に合わせる）
- 12ヶ月目中央値 約15万円。フォロワー2万超で本体の達成確率が2倍になる（感度分析）ため、**投稿を止めないことがプログラム販売の生命線**

## 3. Layer 3: 習慣トラッキングLINEアプリ（スケール装置）

- KAITAI MATCHで使ったLIFF/LINEの開発スキルを転用。**プログラム受講者の提供ツールとして1〜3ヶ月目に最小構成で開発**（習慣チェックイン・リマインド・週次振り返り）
- プログラムの提供品質と差別化に効く（「アプリ付き」は個人コーチとの決定的な差）
- 10ヶ月目からB2Cサブスク公開（1,480円/月）: 受講卒業生の継続利用+メディアからの流入
- 12ヶ月時点の収益貢献は小さい（中央値1万円）が、24ヶ月目以降に**本人の面談時間と収益を切り離す**中核資産。運用コストはLINE無料枠+serverless無料枠で固定費上限内

## 6. KPI管理体系（10指標）

| 指標 | 定義 | 目標値 | 計測 | 頻度 |
|---|---|---|---|---|
| **リード数** | 無料相談予約数 / note新規読者 | 6M: 8件/月 → 12M: 25件/月 / 読者500→1,500 | 予約システム / note解析 | 週次 |
| **CVR** | ①LP→相談予約 ②相談→成約 | ①3〜5% ②**25%（最重要）** | LP計測 / 相談ログ | 週次 |
| **CTR** | リーチ→プロフ遷移 / LP誘導クリック | 1.5〜3% / 10%+ | IGインサイト+UTM | 週次 |
| **CAC** | 広告費÷成約数（相談CPA÷成約率） | **客単価の40%以内（約8万円）。超過で広告停止** | 広告管理+Stripe突合 | 月次 |
| **CPA** | 無料相談1件の広告コスト | 1.2万円以内 | 広告管理画面 | 週次(広告期) |
| **ROAS** | プログラム売上÷広告費 | 250%以上 | 月次突合 | 月次 |
| **LTV** | 受講者: 198,000+卒業後サブスク / 読者500円 | 受講者21万円→アプリで漸増 | 四半期再計算 | 四半期 |
| **チャーン率** | プログラム中途解約 / アプリ・会員解約 | ≤5% / ≤7% | Stripe・note | 月次 |
| **NPS** | 受講者の卒業時サーベイ | **+50（事例・紹介の源泉。低ければ商品を直す）** | Googleフォーム | 卒業ごと |
| **指名検索数** | サービス名・屋号の検索 | 6M:100 → 12M:500/月 | GSC・Googleトレンド | 月次 |

運用リズム: 週次15分（相談数・CVR・投稿指標）→ 月次1時間（CAC/ROAS・成約率・解約）→ 四半期（LTV・NPS・価格とキャパの見直し）。

## 7. 外的要因の仮説とリスク

| 要因/リスク | 仮説・対策 |
|---|---|
| 稼働時間 | 週30〜40時間前提。面談は12ヶ月目でも週10〜12時間に収まる設計（キャパ月9件） |
| 下振れ（p10=月23万） | このモデル最大のリスクは「相談が入らない/成約しない」。6ヶ月目チェックポイントで価格・導線・ターゲットの順に修正。**モデル替えは18ヶ月目まで我慢** |
| 広告アカウント停止・CPM高騰 | 健康系はMeta審査が厳しい → 「治る」系表現ゼロ・習慣コーチングとして出稿。Meta+Google両建て。CPA1.2万で保守設定済み |
| SNSアルゴリズム | 月3%確率でリーチ半減3ヶ月（織込済）。広告と指名検索が代替流入になる |
| 薬機法・景表法・医療広告 | 効果保証と治療表現を全面禁止。医療対象者は受け入れず受診案内（除外基準を明文化）。ビフォーアフター表現は体験談の枠+打消し表記 |
| 特商法 | 高額・継続サービスのため表記/解約規定を厳格に。相談でのセールスは録画同意+クーリングオフ準拠運用 |
| 返金・クレーム | 返金規定明文化・NPS+50を品質KPIに。初期モニターで商品を磨いてから広告をかける順序を厳守 |
| 為替 | 150±10円。外貨比率1割未満で軽微 |
