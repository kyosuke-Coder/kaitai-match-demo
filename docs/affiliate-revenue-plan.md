# 収益化プラン：解体×住まい特化型リードジェネレーションサイト

作成日: 2026-08-30
目標: **12ヶ月で月の手取り100万円**（サイト収益→口座入金）
制約: PC or iPhone 1台 / 月間固定費 上限8,000円

---

## 0. 結論（このプランの骨子）

- **ジャンル: 「解体・空き家・住まいの出口」特化の高単価リードジェネレーション**
  - KAITAI MATCHで既に持っている解体業界の知識・人脈をそのまま武器にする
  - 1人の訪問者から複数回収益化できる導線（解体見積→土地売却査定→不用品回収→外構）
- **収益源は3層**: ①ASPアフィリエイト → ②解体業者との直接契約（送客単価2〜5万円）→ ③KAITAI MATCH本体への送客
- **外貨(ドル)は第2トラック**: 6ヶ月目以降、時間の10%以内でGumroad等の英語圏デジタル商品を実験
- 手取り100万円/月 ≒ **売上135〜150万円/月**が必要（所得税・住民税・国保・事業税を考慮、青色申告前提）

## 1. なぜこのジャンルか（選定理由）

### 候補比較

| ジャンル | 単価 | 競合 | あなたとの相性 | 判定 |
|---|---|---|---|---|
| 金融(クレカ・FX) | 高(1〜4万) | 極高。企業サイト支配 | なし | ✕ |
| 転職 | 高(1〜2万) | 高 | なし | △ |
| VOD・物販 | 低(数百〜数千) | 高 | なし | ✕ |
| **解体・空き家・住まいの出口** | **高(0.5〜5万)** | **低〜中。個人でも戦える** | **業界知識・デモあり** | **◎** |
| 英語圏ニッチサイト | 中 | 高。立ち上がりが遅い | 中 | △(第2トラック) |

### 追い風（マクロ）
- 空き家は全国900万戸超で増加中。相続→解体→売却の需要は構造的に伸びる
- 解体は「人生で1回、相場が分からない、業者選びが不安」= 検索意図が強く比較コンテンツが刺さる
- 大手メディアがまだ本気で取りに来ていないローカル×ニッチ領域

### 収益導線が多重（ここが最大の強み）
「実家を解体したい人」は同時に以下の見込み客でもある:
1. 解体一括見積もり（ASP案件 or 直接契約）
2. 土地・不動産の売却査定（ASP高単価案件）
3. 不用品回収・遺品整理（ASP案件）
4. 外構・エクステリア、住宅ローン借り換え等の周辺案件

1訪問者 × 複数CVで、同じアクセス数でも収益が2〜3倍になる。

## 2. 収益モデルと数値計画

### 目標達成時の内訳イメージ（月商135万円）

| 収益源 | 単価 | 件数/月 | 月額 |
|---|---|---|---|
| 解体業者との直接契約リード | 25,000円 | 25件 | 62.5万 |
| 解体一括見積ASP | 12,000円 | 20件 | 24万 |
| 不動産売却査定ASP | 15,000円 | 20件 | 30万 |
| 不用品回収・周辺ASP | 6,000円 | 20件 | 12万 |
| 外貨トラック(Gumroad等) | - | - | 5〜10万 |
| **合計** | | | **約135万** |

### 必要トラフィックの逆算
- 成約系CVR: マネーページで2〜4%を想定
- 必要CV 85件/月 → 必要な「意図の強い」訪問 約3,000〜4,000/月 → サイト全体で月2〜4万セッション
- ローカルページ(市区町村×解体費用)は1ページ100〜500PV/月でも成約に直結するのが強み

### 直接契約が伸びの本体
ASP経由は単価が固定だが、**地場の解体業者と直接「1リード2〜5万円」で契約**すれば同じ問い合わせの価値が2倍以上になる。KAITAI MATCHの事前登録営業と完全に同じ相手に営業できる（=一石二鳥）。電話発信・フォーム問い合わせを計測できる仕組み (専用LINE・専用フォーム) で担保する。

## 4. マイルストーン

### 12ヶ月目標（ストレッチ）
- 月商135万円 → **手取り100万円/月**
- 直接契約業者 8〜12社、月間2〜4万セッション、LINE登録1,500人

> **正直な見立て:** ゼロから12ヶ月で月100万はアフィリエイト実践者の上位数%の水準。確率を上げる設計（高単価×多重導線×直接契約）にしているが、**ベースケースは12ヶ月で月30〜50万円**。その場合も同じ資産の上に18〜24ヶ月で100万到達を狙える。

### 6ヶ月目標
- **月収15〜30万円**（最初の直接契約2〜3社を含む）
- 公開ページ 120本（うち市区町村ページ80本）
- 月間8,000〜15,000セッション、CV 15〜25件/月
- 外貨トラックの実験開始（英語圏向けデジタル商品 or 英語版コンテンツ1本）

- **初収益発生、月収1〜5万円**（ASP成約 3〜8件）

## 5. 外貨トラック（ドル/ユーロ）の位置づけ

**6ヶ月目までは着手しない**（リソース分散が最大の失敗要因のため）。6ヶ月目以降、時間の10%以内で:

1. **Gumroad / Lemon Squeezyでのデジタル商品販売（ドル建て・固定費0円）**
   - 例: NotionテンプレートやスプレッドシートToolを建設・トレード系英語圏向けに販売
2. **本サイトの英語版実験**: "demolition cost japan" 等、在日外国人・海外投資家向け空き家コンテンツ（競合ほぼゼロ、KAITAI MATCHへの送客にもなる）

ドル収益はWise / Payoneer受け取りで手数料を最小化。円安局面のヘッジとして意味を持たせるが、100万円達成の主軸には据えない。

## 6. リスクと対策

| リスク | 対策 |
|---|---|
| Google変動・AI Overviewsで検索流入減 | ①LINEリスト化 ②直接契約(検索非依存の資産) ③MEO・SNS・YouTube併用 ④指名検索を作る |
| ASP案件の終了・単価改定 | 直接契約比率を6ヶ月目以降50%超へ。複数ASPで同案件を比較 |
| ステマ規制(景表法) | 全ページに「PR/広告」表記。体験談の捏造をしない |
| 直接契約の未計測・未払い | 専用フォーム/専用LINE/計測用電話番号でリードを自分側で記録。月次レポートを業者に送る |
| モチベーション枯渇(3ヶ月無収益期) | 週次の公開本数をKPIにする(収益は遅行指標)。3ヶ月目標を「初収益」に置いているのはこのため |

## 7. KAITAI MATCHとの関係

このメディアは単なるアフィリエイトサイトではなく、**KAITAI MATCH本体の集客資産**になる:
- 施主側リード → 解体業者への送客実績 → 業者がKAITAI MATCHに登録する動機
- 直接営業の接点がそのまま事前登録営業になる
- 将来メディア+マッチングで「解体領域の垂直統合」を1人で持てる

メディアで月30万でも稼げていれば、KAITAI MATCHの開発を続ける資金と業界接点が手に入る。
