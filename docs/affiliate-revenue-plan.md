## 0. 結論：何をやるか

ジャンル（セルフケア）起点をやめ、**持っているスキルが直接競争力になる構成**に切り替える。

```
資産の棚卸し:
  SEO/MEO/AIOの実務経験 → 「サービスとして売る」は本業とバッティング
                          → 「自分の資産に使う」は営業行為ではない = 最大の武器
  AI活用スキル           → 商品そのもの・制作の10倍速化・発信テーマの3役
  開発力(LIFF実績)       → ストア/計測/自動化を自作でき固定費制約が消える

三層モデル（すべて自分の資産、顧客サービスなし）:
  L1【商品】デジタルECストア: 業務テンプレート・AI活用キット（在庫ゼロ・粗利90%超）
      国内: BOOTH / note / 自作ストア(Stripe)　外貨: Etsy / Gumroad
      価格ラダー: 単品1,500〜3,000円 → バンドル9,800円 → 動画付きツールキット34,800円(7ヶ月目〜)
  L2【集客】検索・AIO起点メディア: 「AIで仕事を速くする」実務ブログ
      本職のキーワード選定・AIO最適化スキルをフル投入。SNS週5の消耗戦をやらない
  L3【追加キャッシュポイント】アフィリエイト+広告（SaaSツール紹介等）+ メールリスト
```

**「プラットフォームを育てて広告収益」の検証結果**: ディスプレイ広告単体はRPM数百円で月100万に月200万PVが必要なため主軸にできない（キャッシュポイントの1つとして残す）。主軸は自社デジタル商品の販売。

### シミュレーション結果（2万回試行・保守的に再校正済み）

| 指標 | A: 副業のまま | B: 専業化スイッチあり※ |
|---|---|---|
| 手取り100万 12ヶ月以内 | 9.0% | 11.2% |
| 同 18ヶ月以内 | 24.3% | 31.4% |
| **同 24ヶ月以内** | 36.8% | **46.0%** |
| 12ヶ月目 月利益 中央値 | **34.5万円** | 34.7万円 |
| 12ヶ月時点 月20万以上 | 71.9% | 72.0% |

※月利益40万×3ヶ月継続で専業化（稼働1.8倍）するルール。このトリガーを24ヶ月以内に踏める確率は83%。

**正直な位置づけ:** 本業を維持する分、12ヶ月100万の確率はv6（フルコミット高単価型26.8%）より下がる。その代わり①給与という下方保護が残る ②同業バッティングが消える ③12ヶ月で月34万（中央値）＝**給与+34万の生活になり、24ヶ月100万が五分弱**。リスク調整後ではこちらが健全。

## 1. L1: デジタルECストア（商品）

### 商品レーン（1ヶ月目に3レーン試し、3ヶ月目に勝者へ集中）
1. **個人事業主・フリーランス向け 業務効率キット**（国内）: 経理・請求・案件管理・レポートのスプレッドシート/Notionテンプレ+AI活用手順書。※集客支援系・ローカル店舗向けは作らない（本業バッティング回避）
2. **英語圏向け AIワークフローテンプレート**（外貨）: prompt workflows, AI-assisted planners（Etsy/Gumroad、Pinterest集客、11〜1月の季節需要に初出品を間に合わせる）
3. **クリエイター/副業者向け 制作効率キット**（国内外）

### 価格ラダー（読者LTVを上げる装置。v4の教訓）
- 単品 1,500〜3,000円 → 3ヶ月目からバンドル 9,800円 → 7ヶ月目から動画解説付きツールキット 34,800円（完全セルフサーブ。稼働を食わない高単価）
- 販路: BOOTH・note（国内、固定費0）/ Etsy・Gumroad（外貨）/ 自作ストア+Stripe（手数料最小・データ自前）

## 2. L2: 検索・AIO起点メディア（集客）

- 月8〜10本の実務記事（平日夜にAI併用で1本/1〜2晩ペース）。テーマ: AI活用×業務効率の「やってみた+テンプレ配布」型
- 本職スキルの投入点: キーワード選定（購買意図×競合弱）、AIO対策（AI検索に引用される構造化・一次情報）、内部リンク設計
- 記事→①ストア誘導 ②メールリスト登録（テンプレ無料版を特典に）③アフィリエイト
- SNSは週1〜2の告知運用のみ（消耗戦をしない。Pinterestは英語圏商品用に自動運用）

## 3. L3: 追加キャッシュポイント

- **アフィリエイト**: 記事内で実際に使うSaaS・ツール紹介（もしも/A8＋各ツールの直パートナープログラム。ローカル集客系ツールは扱わない）
- **広告**: セッションが月3万超えたらAdSense/Ezoic系を追加（おまけ扱い）
- **メールリスト**: 週1配信→バンドル・ツールキットのローンチ販売。プラットフォーム依存を消す本丸資産

## 6. KPI管理体系（10指標）

| 指標 | 定義 | 目標値 | 計測 | 頻度 |
|---|---|---|---|---|
| **リード数** | 月間セッション / メールリスト登録 | 6M: 4千 → 12M: 1万 / 12M: 1,000人 | GA4・GSC / 配信ツール | 週次 |
| **CVR** | セッション→購入 / リスト→ツールキット | 0.35%（1%超えたら広告解禁） / 月0.4% | Stripe・各販路÷GA4 | 月次 |
| **CTR** | 検索結果CTR / 記事→ストア誘導クリック率 | 3〜5% / 8%+ | GSC / GA4イベント | 週次 |
| **CAC** | （広告解禁後）購入1件あたり広告費 | 粗利の40%以内 | 広告管理＋UTM | 広告期・月次 |
| **CPA** | リスト登録1件あたりコスト | 300円以内（広告時） | 同上 | 広告期 |
| **ROAS** | 広告売上÷広告費 | 250%未満は停止 | 月次突合 | 月次 |
| **LTV** | 購入者LTV（リピート・バンドル込み） | 初回3千円→12Mで6千円 | Stripe顧客データ | 四半期 |
| **チャーン率** | リスト購読解除率 | 月2%以下 | 配信ツール | 月次 |
| **NPS** | 購入者サーベイ（同梱リンク） | +30（テンプレ改善の入力） | Googleフォーム | 四半期 |
| **指名検索数** | ストア名・ブランド名の検索 | 12M: 300/月 | GSC | 月次 |

運用リズム: 週次15分（セッション・CTR・売上）→ 月次1時間（レーン別損益・CVR・リスト）→ 四半期（LTV・NPS・レーン撤退/集中判断）。

## 7. 外的要因の仮説とリスク

| 要因/リスク | 仮説・対策 |
|---|---|
| **本業バッティング** | ローカル店舗向け・集客支援系の商品/記事/アフィリエイトを一切作らない（本計画の絶対制約）。就業規則の副業規定は着手前に確認 |
| AI検索による検索流入減 | 月-1.5%の逓減を織り込み済み。AIOスキルで「AIに引用される側」に回る＋リスト・指名検索で脱依存 |
| 検索アルゴリズム変動 | 月3%確率でリーチ4割減×3ヶ月（織込済）。販路4つ＋リストで分散 |
| テンプレ市場のAI飽和 | 「作れる」だけの商品は死ぬ→ 実務データ・運用手順・動画解説を付けた「使いこなせる」商品で差別化 |
| マーケットプレイス規約・手数料 | Etsy/BOOTH依存を避け自作ストアとリストを本丸に |
| 副業の時間切れ | 平日=記事・改善、土日=商品制作の固定リズム。AI併用前提の工数で設計済み。専業化トリガー(40万×3ヶ月)を明文化 |
| 為替 | 150±10円。外貨比率2〜3割になるため円高10円で月売上-2〜5%程度 |
| 確定申告・住民税 | 副業収益は開業届＋青色申告。住民税は普通徴収を選択 |
