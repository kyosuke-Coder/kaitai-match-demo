# 収益化プラン：自律神経・QOL特化メディア（SNS起点モデル）

作成日: 2026-08-30（v2: ジャンルを自律神経・QOL系に決定）
目標: **12ヶ月で月の手取り100万円**（サイト/アカウント収益→口座入金）
制約: PC or iPhone 1台 / 月間固定費 上限8,000円 / 外貨(ドル)トラックを併設

---

## 0. 結論（このプランの骨子）

- **ジャンル: 「自律神経を整えてQOLを上げる」ライフスタイル発信**（睡眠・ストレス・疲労回復・習慣）
- **このジャンルで個人が勝つ唯一の型は「SNS起点 × LINEリスト × 自社デジタル商品」**。
  健康系はYMYL領域のためSEOは病院・製薬・大手メディアが支配しており、ブログSEO単独で100万は現実的に不可能。逆にSNS（Instagramリール/TikTok）では自律神経系コンテンツは最も伸びやすい部類。
- **収益は3層**: ①アフィリエイト（睡眠・カウンセリング等の高単価案件）→ ②自社デジタル商品（ここが100万の本体）→ ③外貨: 英語圏向けウェルネス系デジタルテンプレート（Gumroad/Etsy、ドル建て）
- iPhone1台制約と最高に相性が良い（リール撮影・編集・投稿が全部スマホで完結）
- 手取り100万円/月 ≒ **売上135〜150万円/月**（税・国保考慮、青色申告前提）

## 1. このジャンルの構造（先に知っておくべき現実）

### 勝てない場所
- 「自律神経失調症 治し方」「動悸 原因」のような**症状・疾患キーワードのSEO**。Googleは医療機関・専門メディアしか上位に出さない（YMYL/E-E-A-T）。ここに記事を書いても読まれない。
- 効果効能をうたう発信。「治る」「改善する」は**薬機法・景表法違反**のリスク。医療者でない限り「体験」「習慣」「セルフケア」の枠で語る。

### 勝てる場所
- **SNSのショート動画・図解**。「寝る前3分のルーティン」「自律神経が乱れてる人の朝の特徴5選」系は保存・シェアされやすく、無名でも伸びる実績が多いジャンル。
- **「悩みが慢性的で、購買が継続的」**: 睡眠・疲労・ストレスは解決欲求が強く、寝具・リカバリーウェア・カウンセリング・オンラインヨガ等、高単価〜継続課金の案件が豊富。
- **自社商品**: このジャンルの月100万プレイヤーはほぼ全員、アフィリエイトではなく**自分の商品（習慣改善プログラム・講座・テンプレート）**で稼いでいる。アフィリエイトは入口収益と信頼形成の役割。

### 発信者としての信頼の作り方（個人の武器）
- 「自分のQOL改善の記録」を一次情報として発信（体験は薬機法の外で語れる最強の素材）
- 睡眠健康指導士・アンガーマネジメント等の**取得しやすい民間資格**を早期に取ってプロフィールに載せる（E-E-A-TとCVRの両方に効く）
- 書籍・論文の引用を型にする（「〜という研究がある」+出典）

## 2. 収益モデルと数値計画

### 目標達成時の内訳イメージ（月商135万円 / 12ヶ月目）

| 収益源 | 単価 | 件数/月 | 月額 |
|---|---|---|---|
| 自社商品: 習慣改善プログラム/講座 | 19,800円 | 35件 | 69万 |
| 自社商品: 低単価商品(note/Brain/テンプレ) | 1,980円 | 100件 | 20万 |
| アフィリエイト: 寝具・マットレス | 6,000〜15,000円 | 15件 | 15万 |
| アフィリエイト: オンラインカウンセリング/ヨガ/宅食など | 3,000〜10,000円 | 25件 | 15万 |
| 外貨: 英語圏デジタルテンプレート(Gumroad/Etsy) | $9〜29 | 60件 | 15万($1,000前後) |
| **合計** | | | **約135万** |

### 逆算KPI（12ヶ月目時点）
- Instagram/TikTokフォロワー: 3〜5万人（リール週5本×12ヶ月の複利）
- LINE公式リスト: 3,000人（フォロワーの6〜10%を無料特典で誘導）
- 自社商品CVR: リスト向けローンチで1〜3%
- ブログは「SNSプロフィール→詳細記事→LINE登録」の受け皿として60〜100記事（SEOは睡眠グッズ比較などYMYL外のみ狙う）

### なぜアフィリエイト主軸ではなく自社商品主軸か
健康系ASP案件は単価3千〜1.5万円。アフィリエイトだけで135万を作るには月100件超の成約が必要で、YMYLでSEOが使えない以上ほぼ不可能。**同じリストに19,800円の自社商品を売れば件数は1/3以下で済む**。アフィリエイトは「まだ商品がない期間の収益」と「おすすめ紹介による信頼形成」に使う。

## 4. マイルストーン

### 12ヶ月目標（ストレッチ）
- 月商135万円 → **手取り100万円/月**

> **正直な見立て:** このジャンルの100万/月は「メディア運営」というより「SNS発信者としての事業構築」で、属人性が高く、伸びの分散が大きい（同じ努力でフォロワー3千の人も10万の人もいる）。ベースケースは**12ヶ月で月20〜40万円**。ただし当たった場合の上限は解体リードジェンより高く、月200〜300万も存在するジャンル。鍵は「3ヶ月続けて型を見つけられるか」。

## 5. 外貨トラック（ドル/ユーロ）

このジャンルは外貨と相性が良い。**英語圏ウェルネス市場向けのデジタルテンプレート販売**を並走させる:

- 商品: Notion製 Sleep Tracker / Habit & Mood Journal / Morning Routine Planner、印刷用PDF（Etsyのprintable市場）
- 販路: Gumroad・Etsy（固定費ほぼゼロ、ドル建て決済）。受け取りはWise/Payoneerで手数料最小化
- 強み: 日本語版の自社商品と**中身を共用できる**（21日間ワークブックの英語版化など、制作コストが二重にならない）
- 配分: 時間の10〜20%。Week 4から市場調査、3ヶ月目から出品開始、6ヶ月目に3〜5点
- 現実的な期待値: 6ヶ月で月$100〜300、12ヶ月で月$500〜1,500。主軸ではなくヘッジ+複利枠

英語圏向けSNS発信（Pinterest経由のテンプレート集客）は、日本語アカウントが軌道に乗った後の拡張オプション。

## 6. リスクと対策

| リスク | 対策 |
|---|---|
| 薬機法・景表法違反（最重要） | 「治る・効く・改善」を使わない。体験と習慣の枠で語る。NG表現チェックリストを運用。医療相談には答えない |
| ステマ規制 | 全アフィリエイト投稿・記事に「PR/広告」明記 |
| SNSアルゴリズム変動・アカウントBAN | Instagram+TikTok+YouTube Shortsの3面展開。**LINEリストが本体資産**（フォロワーは借り物、リストは自分のもの） |
| 3ヶ月伸びない | 週次で保存率・フォロー転換を分析し型を入れ替える。60本投稿して型ゼロなら切り口(ペルソナ)ごと変える |
| 属人発信の消耗 | ネタを5カテゴリ×ストック制で仕組み化。撮影は週1でまとめ撮り |
| 自社商品が売れない | いきなり19,800円を作らない。無料特典→1,980円→19,800円の階段で各段の反応を検証してから次を作る |
