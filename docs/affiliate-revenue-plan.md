# 収益化プラン v5：セルフケア三層モデル（B2B受託 × 非属人メディア × 高単価講座）

作成日: 2026-09-02（v5: 目標「12ヶ月で手取り100万」を固定制約とし、事業モデル側を変更）
目標: **12ヶ月で月の手取り100万円**（月利益135万円）
制約: PC or iPhone 1台 / 月間固定費 上限8,000円 / テーマはセルフケア（自律神経・睡眠・QOL）を維持

---

## 0. 結論：なぜ三層モデルか

v4までの検証で証明されたこと: **視聴者数に価格がつく収入（メディア）だけでは、12ヶ月で135万に届く確率は1%未満**（読者LTVの物理的上限のため）。目標を固定するなら、**労働に価格がつく収入（B2B受託）を主砲**に据え、メディアは「営業装置 兼 長期資産」に役割を変える。

```
Layer 1【現金】 ウェルネス企業向けSNS運用代行・ショート動画制作の受託
                → 自分の非属人アカウントがそのままポートフォリオ＝営業資料
                → 12ヶ月目中央値 約46万円（4〜5社×10〜15万円）

Layer 2【資産】 セルフケア非属人メディア（SNS→note→商品、v4設計を週3投稿に縮小運用）
                → 12ヶ月目中央値 約13万円 ＋ 外貨テンプレート（Gumroad/Etsy）

Layer 3【拡張】 198,000円の12週間 習慣改善プログラム（7ヶ月目〜、半属人=声・実名）
                ＋ 法人向けセルフケア研修・ワークショップ 30万円/回（9ヶ月目〜）
                → 12ヶ月目中央値 約25万円
```

3層は独立ではなく相互強化する: メディアが伸びるほど受託の成約率と単価が上がり（実績の証明）、受託先の現場知識がメディアのネタになり、両方の信頼が高単価講座を売る。

### シミュレーション結果（2万回試行）

| 指標 | 値 |
|---|---|
| **手取り100万を12ヶ月以内に達成** | **14.6%** |
| 同 18ヶ月以内 | **46.8%** |
| 同 24ヶ月以内 | 64.0% |
| 12ヶ月目の月利益 中央値 | **86万円** |
| 12ヶ月時点で月50万以上 | 91.8% |
| 12ヶ月時点で月30万以上 | 99.3% |

v4（メディア単独）比で12ヶ月達成確率は16倍。かつ下振れが硬い（p10でも月52万）。**「12ヶ月で最低50万はほぼ確実に作り、100万は6〜7回に1回引ける。引けなくても18ヶ月でほぼ五分五分」**が正直な期待値。

### 感度分析（どこを頑張ると確率が跳ねるか）

| 条件 | 12ヶ月達成確率 |
|---|---|
| ベース | 14.6% |
| クライアント単価を15万円以上に引き上げ成功 | 25.0% |
| 外注化して6社同時運用 | 18.5% |
| **メディアがフォロワー2万超（受託営業への追い風）** | **66.1%** |

→ 優先順位: ①単価交渉（安請けしない・値上げ前提の契約）②メディアを捨てない（B2Bの成約率を引き上げる最大レバー）③型が固まったら編集外注。

## 1. Layer 1: B2B受託（現金エンジン）

### 商品
- **SNS運用代行**（ショート動画・図解の企画/制作/投稿/レポート）: 月8万円〜スタート → 実績で15〜25万円へ
- 対象: セルフケア関連のローカル・中小事業者＝**整体院・鍼灸院・ピラティス/ヨガスタジオ・パーソナルジム・サウナ施設・寝具/快眠グッズD2C・宿泊(リトリート)**
- 彼らの共通課題: SNSが必要なのは分かっているが、時間もノウハウもない。制作単価の相場感も曖昧→ 「業界特化で実績が見える」個人に発注しやすい

### 営業プロセス（数字で管理）
```
月60接触（DM/問い合わせフォーム/紹介） → 商談化率10% = 6商談 → 成約率25〜30% = 1〜2社/月
稼働上限: 4〜6社（週3投稿×社。編集を1本500〜1,500円で外注化して上限を6社へ）
解約率: 月7%目標（レポート送付と月次定例で防ぐ）
```
- 営業文面の核: 「あなたの業界で私のアカウントはこう伸びています」＝Layer 2が営業資料
- 初月は8万円のスモールプラン+3ヶ月契約 → 成果レポートを根拠に4ヶ月目から増額交渉
- クライアントLTV ≒ 単価12万×平均継続14ヶ月 ≒ **170万円**。1社の獲得に営業60接触かけても割に合う

### 12ヶ月ロードマップ
2ヶ月目に営業開始 → 3ヶ月目 1〜2社(10万) → 6ヶ月目 3社(28万) → 12ヶ月目 4〜5社×単価12〜15万(46万〜)

## 2. Layer 2: 非属人メディア（資産エンジン・営業装置）

v4の設計を**週3投稿に縮小して継続**（受託に時間を回すため。やめない事が重要）:
- ファネル: SNS（図解・テキスト動画）→ note無料記事 → 有料note 1,980円 / メンバーシップ 1,480円 / アフィリエイト
- 外貨トラック: 英語圏Self-Care Journal等テンプレート（Gumroad/Etsy、Pinterest集客、11〜1月の季節山に合わせ3ヶ月目までに初出品）
- 12ヶ月目中央値 約13万円。ただし本当の価値は**受託営業の成約率と講座の販売力を作ること**（フォロワー2万超で達成確率66%になるのはこの効果）

---

## 3. Layer 3: 高単価（レバレッジ）

- **12週間 習慣改善プログラム 198,000円**（7ヶ月目〜）: 週1のオンライン面談+デイリーチェック。医療でなく習慣コーチングの枠。半属人（声・実名は出す、顔は任意）。note読者・会員から月1〜3件
- **法人向けセルフケア研修 30万円/回**（9ヶ月目〜）: 受託クライアントとその周辺（従業員の睡眠・ストレス対策研修）。B2B接点をそのまま二次利用
- 12ヶ月目中央値 約25万円。ここはCVRが低くても単価が吸収する

## 4. 固定費設計（上限8,000円 → 通常運用 約1,500円）

| 項目 | 月額 |
|---|---|

編集外注費・広告費は固定費ではなく**売上連動の変動費**（受託収入から支出、粗利85%を維持）。

## 6. KPI管理体系（10指標を三層に対応）

| 指標 | 定義（B2B / メディア） | 目標値 | 計測 | 頻度 |
|---|---|---|---|---|
| **リード数** | 営業接触数・商談数 / note新規読者 | 60接触・6商談/月 / 読者500→1,500/月 | 営業管理シート / note解析 | 週次 |
| **CVR** | 商談化率・成約率 / 読者→購入 | 10%・25% / 2.0% | 同上 | 月次 |
| **CTR** | 営業DM返信率 / リーチ→プロフ遷移 | 8〜12% / 1.5〜3% | 送信記録 / IGインサイト | 週次 |
| **CAC** | 1社獲得の営業時間換算+広告 / 読者獲得単価 | クライアントLTVの5%以内 / 185円以内 | 時間ログ・広告費 | 月次 |
| **CPA** | 講座1件あたり販促費 | 粗利の1/3以内 | Stripe+UTM | ローンチごと |
| **ROAS** | 広告テストのLTVベース回収率 | 150%未満は即停止 | 月6,000円テスト枠 | テストごと |
| **LTV** | クライアント約170万 / 会員約2万・読者500円 | 単価UPと継続で伸ばす | 四半期再計算 | 四半期 |
| **チャーン率** | クライアント解約率 / 会員解約率 | ≤7% / ≤6% | 契約記録 / note | 月次 |
| **NPS** | クライアント四半期survey / 購入者survey | +30 / +20（解約の先行指標） | Googleフォーム | 四半期 |
| **指名検索数** | 屋号・アカウント名の検索 | 6M:100 → 12M:500/月 | GSC・Googleトレンド | 月次 |

運用リズム: 週次15分（営業数・返信率・投稿指標）→ 月次1時間（成約率・チャーン・単価）→ 四半期（LTV・NPS・値上げ判断）。

## 7. 外的要因の仮説とリスク

| 要因/リスク | 仮説・対策 |
|---|---|
| 稼働時間 | **週30〜40時間を投下できる前提**（副業20時間なら受託上限2〜3社となり12ヶ月中央値は約50万に低下） |
| SNSアルゴリズム変動 | 月3%確率でリーチ半減3ヶ月（織り込み済）。受託収入は影響を受けないため事業全体の耐性は高い |
| 受託の景気感応度 | 中小のSNS予算は景気に敏感 → 成果レポートで「削られない枠」に入る。解約率7%で織り込み |
| 単価下落（AI制作の普及） | 制作単体は値下がりする仮説 → 「企画+業界知識+運用+レポート」のパッケージで売り、制作だけ売らない |
| 薬機法・景表法 | 自分の発信と受託納品の両方にNG表現チェックを適用（受託先がクリニック系の場合は特に医療広告ガイドライン確認） |
| 為替 | 150±10円。外貨は全体の1割未満で影響軽微 |
| 講座のクレーム/返金 | 特商法表記・返金規定を明文化。効果保証をしない（習慣サポートとして販売） |
