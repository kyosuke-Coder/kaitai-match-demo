# 収益化プラン：セルフケア特化・非属人メディア（SNS→note→商品ファネル）

作成日: 2026-08-30（v3: セルフケア発信・非属人運用・note中心ファネルに確定）
目標: **12ヶ月で月の手取り100万円**（口座入金ベース）
制約: PC or iPhone 1台 / 月間固定費 上限8,000円 / 外貨(ドル)トラック併設

## 0. 確定した運用方針

- **テーマ: セルフケア**（自律神経・睡眠・ストレス・疲労回復を「習慣とセルフケア」の枠で発信。医療の話をしない＝薬機法リスクも下がる）
- **非属人運用**: 顔出し・名前出しなし。図解カルーセル、テキスト動画（AIナレーション/字幕のみ）、Canvaテンプレで量産できる形式に統一
- **ファネル: SNS（発見）→ note（信頼形成・無料記事）→ 商品（有料note・メンバーシップ・アフィリエイト）**
- 非属人の設計原則: 「人」ではなく**「ブランド」への信頼**を作る（統一されたデザイン・語り口・出典明記・シリーズ化）

### 非属人のトレードオフ（設計に織り込み済み）
| | 属人 | 非属人（採用） |
|---|---|---|
| 高単価商品(2万円〜)のCVR | 高い | **低い → 高単価を捨て、低〜中単価×件数×継続課金で積む** |
| 量産・外注化・複数アカウント展開 | 難しい | **容易（12ヶ月目以降の伸びしろ）** |
| BAN・炎上・本人疲弊のリスク | 高い | 低い |
| 事業売却の可能性 | ほぼ無い | ある（属人性ゼロのメディアは売れる） |

## 1. ファネル設計（このプランの心臓部）

```
[発見]  Instagramリール・TikTok・X（同一コンテンツを3面展開）
   │      非属人フォーマット: 図解5枚カルーセル / テキスト動画 / チェックリスト系
   ▼
[信頼]  note 無料記事（SNSプロフィール・投稿末尾から誘導）
   │      「投稿で興味 → noteで深掘り」の役割分担。無料記事の末尾に必ず次の一歩
   ▼
[転換]  ① 有料note単品（980〜1,980円）
        ② noteメンバーシップ（月額980円）← 継続課金の柱
        ③ アフィリエイト（無料記事内で寝具・カウンセリング等を比較紹介）
```

- SNS側は「保存されるノウハウ」に徹し、売り込みをしない（アルゴリズム上も伸びる）
- noteの無料:有料比率は 4:1 目安。無料記事が営業マンの役割
- note手数料（決済+プラットフォームで実質15〜20%）は織り込む。単品が育ったらBrain/Tips/自前決済の併売で手数料を圧縮する選択肢を残す

## 6. リスクと対策

| リスク | 対策 |
|---|---|
| 薬機法・景表法（最重要） | セルフケア・習慣の枠で発信し医療的助言をしない。「治る・効く」不使用。NGリストでセルフチェック。アフィリエイトはPR表記必須 |
| 非属人ゆえの信頼不足→CVR低迷 | デザイン統一・出典明記・シリーズ化でブランド信頼を構築。高単価を狙わず980〜1,980円と月額980円に集中 |
| SNSアルゴリズム変動・BAN | 3プラットフォーム展開+note自体のフォロワー化。メールアドレスが取れるようになったら（自前決済導入時）リスト化も併用 |
| note手数料・規約変更 | 単品が育ったらBrain/Tips/Stripe自前決済を併売。noteに全依存しない |
| 3ヶ月伸びない | 週次で保存率・遷移率を見て型を入れ替え。90本投稿して型ゼロならペルソナ・切り口ごと変更 |
| 量産の消耗 | テンプレ制・ネタストック制・週1まとめ制作。型が固まったら外注化（非属人の利点を使う） |

## 7. KPI管理体系と達成確率（モンテカルロシミュレーション）

### 7-1. 10指標の定義・目標・計測プロセス

| 指標 | この事業での定義 | 目標値 | 計測プロセス | 頻度 |
|---|---|---|---|---|
| **CTR** | ①リーチ→プロフィール遷移率 ②プロフ→note誘導リンクCTR | ①1.5〜3% ②10〜15% | IGインサイト＋リンクにUTMパラメータ | 週次 |
| **リード数** | note新規読者数/月（リスト代替）＋noteフォロワー | 3M: 500/月 → 6M: 1,000/月 → 12M: 2,500/月 | noteアクセス解析＋GA4 | 週次 |
| **CVR** | ①読者→有料note購入 ②読者→メンバーシップ加入 | ①2.0%（1.5%未満は記事末CTA改修） ②0.8% | note売上管理÷読者数。ローンチごとにLP比較 | 月次 |
| **CAC** | 広告での新規note読者1人あたり獲得単価 | 上限 = 読者LTV×0.7÷1.3（現モデルで約185円） | 広告費÷UTM計測の新規読者 | 広告テスト時 |
| **CPA** | 商品購入1件あたり広告費 | 単品: 商品粗利以内 / 会員: LTVの1/3以内 | 広告管理画面＋note売上突合 | 広告テスト時 |
| **ROAS** | 広告経由売上（LTVベース）÷広告費 | **150%未満なら広告停止**、オーガニック専念 | テスト予算月6,000円枠内で判定 | テストごと |
| **LTV** | 会員: 月額×粗利率÷チャーン / 読者: 1読者の期待生涯収益 | 会員 約19,700円 / **読者LTV 500円**（最重要・下記参照） | 四半期に実績値で再計算しモデル更新 | 四半期 |
| **チャーン率** | メンバーシップ月次解約率 | ≤6%。8%超で会員限定コンテンツ強化 | note会員管理画面 | 月次 |
| **NPS** | 購入者・会員への「友人に勧めるか(0-10)」調査 | +20以上。チャーンの先行指標として使う | Googleフォームで四半期サーベイ（非属人ではブランド信頼の代理指標） | 四半期 |
| **指名検索数** | ブランド名でのGoogle検索インプレッション | 6M: 100/月 → 12M: 500/月 | GSC＋Googleトレンド。指名流入はCVRが2〜3倍＝ブランド化の証拠 | 月次 |

**運用リズム:** 週次15分（CTR・リード）→ 月次1時間（CVR・チャーン・CAC/ROAS判定）→ 四半期（LTV再計算・NPS・指名検索→戦略見直し）

### 7-2. ファネルの数式

```
月商 = 読者数 × 読者LTV(月あたり)
読者数 = (新規フォロワー×遷移率0.12〜0.20) + (総フォロワー×1.5〜2.0%)
読者LTV = CVR単品×単価×0.82 + CVR会員×月額×0.8÷チャーン + CVRアフィ×報酬 + CVR講座×単価×0.85
```

### 7-3. シミュレーション結果（2万回試行・24ヶ月）

主要変数に分布を与えて試行（フォロワー獲得力: 対数正規・中央値25人/投稿、CVR・チャーン: 正規分布、バイラル月5%、アルゴリズム変動月3%でリーチ半減3ヶ月、為替150±10円）。

| シナリオ | 12M月利益 中央値 | 月20万@12M | **手取り100万 @12M** | @18M | @24M |
|---|---|---|---|---|---|
| A: v3計画そのまま（低単価×オーガニック） | 12.5万円 | 23% | **0.1%** | 0.6% | 1.1% |
| B: A＋広告再投資ループ | 12.2万円 | 22% | 0.1% | 0.7% | 1.2% |
| C: **単価ラダー改善版**（下記v4） | 20.1万円 | 50% | **0.9%** | 3.9% | 6.8% |

**モデルが示した構造的事実:**
1. **v3の読者LTVは約220円しかなく、広告CPA（中央値251円）を下回る** → 広告で拡大できず、オーガニックの読者数だけでは135万に物理的に届かない（必要読者数6,000人/月 ≒ フォロワー50万規模）
2. 単価ラダーを直すと読者LTVは344円になり、月20万の達成確率が23%→50%に倍増する。**このモデルの最重要KPIは「読者LTV500円」**（500円到達で広告ループが解禁され、確率カーブが変わる）
3. 手取り100万は12ヶ月では確率1%未満。**現実的な位置づけ: 12ヶ月で月20万（五分五分）→ 24〜36ヶ月で100万に挑む長期戦**

### 7-4. シナリオC＝v4修正（モデルに基づく計画変更）

- 有料note単品: 1,480円 → **1,980円**（このジャンルの実勢上限内）
- メンバーシップ: 980円 → **1,480円**（プレミアム化・コンテンツ量で正当化）
- 中単価商品を**24,800円の動画講座**に引き上げ（非属人でも「講座」形式なら売れる。9ヶ月目〜）
- SNS→note遷移率を0.12→**0.20**へ改善することを「型検証」の必達条件に含める（投稿末尾CTA・プロフィール文・ハイライトの継続ABテスト）
- 広告投資は読者LTVが実測500円を超えるまで封印（月6,000円のテスト枠のみ）

### 7-5. 外的要因の仮説（モデルへの織り込み）

| 外的要因 | 仮説 | 扱い |
|---|---|---|
| SNSアルゴリズム変更 | 月3%の確率で発生、リーチ半減が3ヶ月続く | モデルに織り込み済み |
| バイラル | 月5%の確率で+3,000フォロワー級のヒット | 織り込み済み |
| 為替 | 150円±10円。円高でも外貨比率10%強なので影響軽微 | 織り込み済み |
| note手数料・規約変更 | 実質18%が20%超に上がる可能性 → Brain/自前決済併売でヘッジ | 感度小として定数扱い |
| 薬機法の執行強化 | セルフケア・習慣の枠なら影響小と仮定。医療表現ゼロ運用で担保 | 前提条件 |
| AI生成コンテンツの洪水 | 図解・テキスト系の競争激化 → フォロワー獲得力の中央値25人/投稿は これを織り込んだ保守値と仮置き。悪化したら一次体験・独自データで差別化 | パラメータに反映 |
| 広告市況（CPM高騰） | CPA中央値251円と保守的に設定 | 織り込み済み |

**モデルの限界:** 個人の継続率（週5投稿×24ヶ月）は100%と仮定している。ここが崩れると全確率がゼロに近づくため、実質的な最大リスクは外部ではなく執行。

## 8. 決めたこと・変更履歴

- v1: 解体・空き家リードジェネレーション案
- v2: ジャンルを自律神経・QOL系に変更（SNS×LINE×自社商品モデル）
- v3: 発信をセルフケアの枠に確定。非属人運用に確定。ファネルをSNS→note→商品に確定。それに伴い高単価商品を外し、有料note単品+noteメンバーシップ(継続課金)+アフィリエイト+外貨テンプレートの構成に変更。LINEは必須から外し、note中心に一本化
- **v4: KPI体系（CAC/LTV/ROAS/CPA/CVR/リード/CTR/チャーン/NPS/指名検索）を定義し、モンテカルロシミュレーションで達成確率を算出。結果を受けて単価ラダーを再設計（単品1,980円・会員1,480円・講座24,800円）、最重要KPIを「読者LTV500円」に設定。12ヶ月手取り100万の確率は1%未満と判明し、現実的な目標線を「12ヶ月で月20万（確率50%）→24〜36ヶ月で100万」に再設定**
