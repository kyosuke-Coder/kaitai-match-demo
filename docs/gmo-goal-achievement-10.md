# GMOインターネットグループ 目標達成10カ条

> このドキュメントは、本リポジトリにおける目標設定・進捗管理・リーダーシップの判断基準となる「思想」である。
> 何かを実行・提案する際は、「GMO流ランチェスター戦略」とあわせて必ずこの10カ条を参照すること。

我々は、インターネット産業の拡大と、優秀な戦略・優秀な人財の組み合わせにより、ナンバー１ベンチャーの地位を確立した。永遠にナンバー１であるために、この先予想されるインターネット産業の成熟化・戦略の模倣に、いち早く備え、決して真似されない「目標達成力」のノウハウを組織と管理者（以下、リーダー）全員が身に付けなければならない。リーダーとは、会社から経営資源を預かって、その価値を高める使命を負った責任者である。リーダーとは、メンバーの有無は無関係であり、リーダーがその責任を果たすには、目標を達成することが大前提にある。

## 【1】目標とは
1. 目標とは"当面の敵"である。期限の無い目標は無い。期限設定と「自問自答10カ条」で作業が仕事になる。期限は、その場で「何日何時何分まで」と明確に決める。「今日中」「今週中」などの曖昧な表現を使うな。期限は、優先度を検討し、出来るだけ短く設定する。
2. 目標とは、目指す数字である。数値化することにより、初めて「方針」は「目標」に変わる。
3. 目標とは、最低期待値であることを心得よ。リーダーは、一つでも目標達成ができないときは、その責任を取らねばならない。

## 【2】目標を作動させよ
1. 目標は、決めただけでは達成できない。達成にはノウハウがある。
2. 作動とは浸透し、意欲を燃やし、目標に関係する行動以外はせず、結果として目標が達成される状態を言う。
3. 目標作動のためには、手を変え品を変え何種類もの工夫を持て。同じことを繰り返していたら効果は薄くなる。会話だけでなく、形に残さないとメンバーは動かない。メンバーの意欲を測るのは難しいが、行動の質・量が数字に表れる場合もある。
4. 目標は、「計画・予算」と言い換えてはならない。「計画・予算」には達成するものというニュアンスが少ない。

## 【3】目標設定と責任分担
1. トップは、目標をリーダーに与える。このときリーダーには数字に対する責任が生じる。
2. メンバーの目標設定は、リーダーの仕事である。民主主義で行ってはならない。意見を聞いても振り回されるな。
3. リーダーは、メンバーに数字を分担させて責任を果たす。目標は、責任分担制である。
4. リーダーは ①メンバーに目標に対する責任を持たせ ②チェックし、責任を追及することが、仕事である。
5. 責任の追及とは、結果と理由を明確化し、一緒に考え対策を立て、実行することである。

## 【4】目標の純度を高めよ
1. 目標の純度を高めよ。公平性のない目標は、メンバーのやる気を失わせる。
   - 過去のデータを基に客観的に数値化し
   - 方針を示し
   - 個人の考え方、主張、潜在能力は加味せず、90％のメンバーが納得するものにせよ
2. 目標は、「構成比」で作れ。それは「期待値」になる。
3. 目標は、相手一人一人を考えて決めよ。すべての環境・要因を考慮せよ。オリンピックの点数の付け方を参考にせよ。

## 【5】目標に仕掛けを作れ
1. 最低5日おきにメンバーと面談し、数字の申告（見通し・読み）をさせよ。続けていれば、誤差は縮む。
2. 見通し管理を徹底せよ。重要な数字は原則毎日、最低5日ごとに全員で共有せよ。見通し管理をすることで「未来」の目標は「現在」になる。本人に「あと一歩」と自覚させよ。
3. 見通し表は、「見通し数字」の「順位表」である。グラフ、矢印、○×、コメントを加え、メンバーを刺激せよ。
4. 見通し表には、◎／○／△×／×／×× の5段階の記号を書き込め。○は100％以上、100％未満に○は無し。△だけもあり得ない。100％未満は全て×である。
5. データは更新せよ。リアルタイムな情報こそ、価値がある。

## 【6】育成面接を行え
1. メンバーに出して良い感情は、「育ってもらいたい」という愛情のみである。
2. 事実を伝え、自覚させよ。Yesを言わせること。
3. 決め付けない、抽象的にならない、責めてはいけない。
4. 「あと一歩」は言ってはならない。自覚させよ。

## 【7】目標の種類を増やせ
1. 目標の種類は、7〜8種類と多い方が良い。複数の指標に因数分解するなど、原因把握に役に立つ。
2. 達成できないメンバーには、「行動量」の目標を与えよ。「行動量」は多めに与え、必ず達成させるために、毎日チェックせよ。

## 【8】目標と業績評価
1. 業績評価の柱は、目標達成率を利用せよ。そうでなければ、目標を立てる意味が無い。
2. リーダーは、管理目標の比率が多くなり、メンバーは、業績目標の比率が多くなる。

## 【9】報告せよ
1. 問題点とは、原因中の原因を言う。
2. 組織は、問題の巣である。よって、問題の無い組織は無い。問題が無い場合、つきつめるとその原因は二つある。一つは、組織に目標が無いこと、一つは、リーダーそのものが問題の根源であること。
3. リーダーは、問題を見つけ、解決する人である。
4. 問題が解決できないときは、上長に報告せよ。報告は、組織の血である。もっとも大切なリーダーの行動は「報告」であることを認識せよ。報告できないリーダーは去れ。
5. 報告は、数字で行え。「がんばる」「大丈夫」などの文学的表現は使うな。表現が文学的なのは思考が曖昧だからである。
6. お客様対応中以外は、定時で報告せよ。定時報告がなく、催促した場合でも、改めて自ら報告させよ。

## 【10】リーダーとは
1. リーダーは、目標達成やメンバーの成長のため、メンバーの仕事の大切さを説き、誇りを持たせ、「ほめる」「叱る」をバランス良くできて、初めてリーダーである。叱れないリーダーは、目標か組織を犠牲に自己満足をしているだけであり、リーダーは、目標達成やメンバーの成長のために、嫌われることを決して恐れない。また、リーダーは、目標を達成したときはもちろん、メンバーの成長のため、常日頃から、タイミングよく、適切に、無条件に、熱意をもって「ほめる」ことができる。
2. 言われたことをただ伝えるだけの伝書鳩はリーダーではない。リーダー自らが行動で示し、指導し、実践させ、適切にほめることができなければ、メンバーは動かない。
3. 仕組みを作っても稼働させなければ意味がない。指示をしたら完了させるまでがリーダーの仕事である。愛をもって繰り返し指導し実践させよ。
4. 繰り返し指導しても実践できない場合、メンバーの適性を見誤っている。愛をもって交代させよ。
5. リーダーは目標を納得し、意欲を100%にせよ！ メンバーは70%の意欲しか返してこない。リーダーの意欲が100%以上あって初めて、メンバーの意欲以上の数値が返ってくる。リーダーが意欲を100％にすることなくして、目標達成はあり得ない！
6. リーダーが目標達成できない場合は、社内解雇か社内倒産あるいは社内統合をさせよ。
7. メンバーは、上長を選べない。成長しないリーダーを持ったメンバーは不幸である。
8. リーダーの指示・命令は強制であり、必ず実行されるものでなければならない。
9. メンバーには、質問形式で「自覚」させよ。返答・反応がないメンバーは、「仕事が出来ない人間の象徴」である。返答・反応をさせよ。ハイの数は多い方が良い。
